# Taste

## Communication
- Prefers communication in Indonesian (Bahasa Indonesia). Confidence: 0.65

## Workflow / Deployment
- When a flow the user already approved and was comfortable with gets restructured, wants the earlier working version restored rather than the new approach patched up. Confidence: 0.6
- Wants each data definition to have a single source of truth across admin pages — a field defined in one page (e.g. Jenis Surat's form builder) must NOT be duplicated/re-defined in another page (e.g. Template), and a page should hold exactly one clear responsibility. Confidence: 0.65
- Considers SSH/terminal operations too risky; prefers GUI-based solutions (e.g. cPanel File Manager, MultiPHP Manager) over command-line steps. Confidence: 0.65

## UI / Localization
- Wants all user-facing text — including framework/Breeze defaults and validation error messages (e.g. Laravel "The email field must be lowercase.") — in Bahasa Indonesia, not English. Confidence: 0.75
