# UI

- Wants newly added UI sections to visually match the site's existing equivalent component (e.g. "make the format the same as the variable input fields") instead of introducing a new style. Confidence: 0.6
- Prefers uploaded/attached files to be viewable (inline preview) before download — a "Lihat" action alongside "Unduh" instead of triggering the download directly. Confidence: 0.6
- Prefers header action buttons laid out side by side in a single row (right-aligned) rather than wrapping onto stacked rows, and labels that don't duplicate their icon (no literal "+" text next to a plus icon). Confidence: 0.6
- Dislikes popups/toasts that flash and vanish too fast — auto-dismissing notifications should stay visible long enough to be read (roughly a second or more), not blink away instantly. Confidence: 0.7
- Wants popups to close with a slow, smooth fade-out (noticeably long transition, e.g. ~700ms) rather than disappearing abruptly. Confidence: 0.6
